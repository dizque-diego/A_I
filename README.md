 # Sistema inteligente de ruta - IA
 # Este proyecto desarrolla un sistema de ruteo inteligente en la ciudad de medellín a través de el sistema metro, teniendo en cuenta 3 Lineas de movimiento, la linea Metro A, B y la linea de metrocable K
 # El sistema utilizara una base de conocimiento compuesta por las estaciones, conexiones, y reglas lógicas,
 # Posteriormente se implementarán los distintos algoritmos de busqueda para calcular rutas posibles desde un origen hasta un destino.
